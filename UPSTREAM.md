# Chapbook engine provenance

Kalam carries the Chapbook EPUB engine as local workspace crates under
`crates/chapbook-*`. These crates are maintained in this repository; Kalam does
not have an automatic upstream update process.

The source originated at [ophymx/chapbook](https://github.com/ophymx/chapbook).
The detailed import record, review history and inherited-file notes are kept in
the archived [`docs/kalam/UPSTREAM.md`](docs/kalam/UPSTREAM.md). That archive is
for provenance only, not a current merge procedure. For current behavior, use
the source, workspace manifests and tests.
